Sprite stack

Four orthographic views become a sprite you can spin. One TypeBox action runs in process, as an HTTP route, from the typed client, and as an MCP tool.

  • typed client

Stacking the car.

Drag the sprite. Arrows turn it.

Carving is a TypeScript port of sprite-stacking by Daniel White, MIT. A voxel survives only where all four views cover it. The volume is cut into layers, ground first. Each layer is rotated, squashed for pitch, and lifted 1px. Ask an agent, pointed at POST /mcp, to make a rotatable pixel-art car.
