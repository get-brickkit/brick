Brick-TS uses the explicit `syncSchema` helper in development and tests, and `brick db generate` / `brick db migrate` for production migrations on SQLite and PostgreSQL. See [Database Schema](/docs/brick-cli/db).

Please see the canonical guide: **[Database Management & Migrations](/docs/database)**.

### Schema

The database guide uses this application-owned table. Apply migrations to the tables declared in your Drizzle schema.

    name: "email",
